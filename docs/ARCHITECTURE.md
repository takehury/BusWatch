# Архитектура

Приложение — обычный Android-проект **без Gradle и без внешних зависимостей**:
сборка идёт через `aapt2` + `javac` + `d8` + `apksigner` (`build_apk.sh`),
что делает её воспроизводимой на любой машине с JDK 17 и Android SDK.

## Слои

```
UI (Android)                     Логика (чистая Java, тестируется на хосте)
├── WatchView  ── рисует UiFrame ├── Geo, Text, Displays
├── WatchUi    ── строит кадр    ├── Board (доска остановок и ЭТА)
├── BusWatchActivity ─ состояние ├── Catalog, Cities, RoutePageParser
└── BusAlertService ─ фон        ├── FeedParser, MiniJson
                                 └── Alert, Selection, FocalList, RouteList
```

- **UiFrame** — список примитивов (круг, скруглённый прямоугольник, дуга, текст).
  `WatchView` проигрывает его на `Canvas`, а тестовый `Preview` — на Java2D.
  Благодаря этому интерфейс проверяется без эмулятора.
- **FocalList / RouteList** — геометрия «рыбий глаз»: строка в центре выше и шире,
  края сужаются по хорде круга. Одна и та же геометрия используется для отрисовки
  и для попаданий пальцем.
- **Catalog** — офлайн-каталог города: маршруты, остановки, упорядоченные списки.
  Для Красноярска списки остановок зашиты, для остальных городов читаются со
  страницы маршрута (`RoutePageParser`) и кэшируются.
- **BusAlertService** — foreground-сервис: раз в 10 с проверяет фид выбранного
  маршрута, при прибытии автобуса на отмеченную остановку дважды вибрирует и
  показывает уведомление.

## Поток данных

1. `BusRepository.loadCities()` — список городов из `assets/cities.json`.
2. `loadCity(city)` — маршруты и остановки из `assets/cities/<id>_*.json`.
3. Пользователь выбирает маршрут → `routeStops()` (офлайн или страница) и
   `fetchRoute()` (фид Bustime) в фоновом потоке.
4. `Board.build()` — для каждой остановки: кто «здесь» и через сколько минут
   следующий автобус.
5. UI обновляется на главном потоке, опрос — каждые 10 секунд.

## Почему без Gradle

Основное приложение не использует AndroidX/Google Play Services, поэтому
сборка сводится к четырём утилитам SDK. Это ускоряет CI и позволяет собирать
APK на машинах без Android Studio.
