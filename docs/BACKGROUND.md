# Ожидание автобуса при выключенном экране

Режим «Ждать автобус» должен разбудить часы даже с погасшим дисплеем. Android
этому активно мешает: в Doze отключается сеть, а производители часов агрессивно
выгружают фоновые приложения. Поэтому используются четыре механизма сразу.

## Что делает приложение

| Механизм | Зачем |
|---|---|
| Foreground-сервис (`dataSync`) | процесс не убивается, пока идёт ожидание |
| Постоянное уведомление | видно, что ожидание активно; система считает сервис важным |
| `PARTIAL_WAKE_LOCK` без таймаута | процессор не засыпает между опросами |
| `AlarmManager.setAndAllowWhileIdle` | раз в минуту будит устройство даже в Doze и перезапускает опрос |

Опрос фида идёт каждые **5 секунд**; при попадании в Doze — через сторожевой
будильник. Будильник переживает **смерть сервиса**: если система остановит
приложение при выключении экрана, будильник раз в минуту поднимает сервис снова,
тот сразу делает проверку и может отправить уведомление. Ожидание автоматически
завершается через **3 часа**.

## Что нужно разрешить пользователю

1. **Уведомления** — при первом запуске приложение запрашивает разрешение.
2. **Работа в фоне** — на Huawei это разрешение обычно выдаётся автоматически;
   отдельного запроса приложение не показывает. На Wear OS проверьте
   «Настройки → Приложения → Автобусы → Батарея → Без ограничений».
3. **Huawei / HarmonyOS** (Watch 3/4, APK-совместимые):
   - Настройки → Батарея → **Запуск приложений** → «Автобусы» → *Управлять вручную*,
     включить все пункты (автозапуск, косвенный запуск, работа в фоне);
   - Настройки → Батарея → **Защищённые приложения** → добавить «Автобусы».
4. **Wear OS** (Pixel Watch, Galaxy Watch): Настройки → Приложения → Автобусы →
   Батарея → **Без ограничений**.

## Если уведомление всё равно не приходит

- Проверьте постоянное уведомление «Ожидание автобуса №…». В его тексте
  обновляются время последней проверки и число машин (например,
  «остановка: Ленина · 3 маш. · 12:34»). Если время «замерло» — систему
  заморозила приложение, добавьте его в «Защищённые приложения».
- Убедитесь, что на часах включён интернет (Bluetooth-тетеринг, Wi-Fi или LTE).
- На Huawei без «Защищённых приложений» система выгружает приложение через 1–2
  минуты после выключения экрана. Приложение это замечает: при возврате на экран
  появляется подсказка «Часы приостанавливали приложение…».
- Учтите ночное время: после 23:00 автобусы могут не ходить, и ожидание просто
  не сработает.

## Ограничения

- Система может ограничивать время работы foreground-сервиса; приложение останавливается
  само через 3 часа, чтобы не жечь батарею.
- Точность прибытия зависит от фида Bustime: позиции обновляются на стороне
  сервиса, обычно раз в 10–30 секунд.
- Вибрация и звук зависят от режима часов (беззвучный режим, «Не беспокоить»).
