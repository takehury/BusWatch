# Источники данных

## Живой фид

Публичный веб-фид проекта **Bustime**:

```
https://busti.me/ajax/bus/?bus_id=<id>
```

Возвращает JSON со списком машин маршрута: координаты, скорость, курс, номер,
направление, следующая остановка и её индекс (`order`). Фид общий для всех
поддерживаемых городов; `bus_id` уникален в пределах города.

Зеркала: `busti.me`, `en.busti.me`. Домен `ru.busti.me` отдаёт те же данные,
но блокирует TLS-рукопожатие JSSE, поэтому в клиенте не используется.

## Каталог городов

- Список городов: главные страницы `busti.me/<city>/` (идентификатор `us_city`).
- Остановки и маршруты: `https://ru.busti.me/api/v1/stops?place=<id>`.
- Упорядоченные остановки маршрута: HTML страницы маршрута
  (`var route0`, `var route1`, `var busstops`).

Скрипт сборки каталога: `tools/extract_stops.py`, исходные выгрузки — `data/`.

## Правовая заметка

Данные принадлежат Bustime и операторам транспорта. Приложение не является
официальным продуктом Bustime; использование — в ознакомительных целях.
Перед публикацией в магазинах приложений уточните условия использования данных
у правообладателя и при необходимости замените источник на официальный API города.
