# Версия 1.28

- Сторожевой будильник теперь ставится из приложения и **переживает остановку
  сервиса**: если система убивает приложение при выключенном экране, будильник
  раз в минуту поднимает его и делает проверку.
- Метка «Жду автобус» снимается сразу после срабатывания, даже если экран открыт:
  состояние синхронизируется с сервисом.
- Если система замораживала приложение, при возврате на экран появляется
  подсказка добавить его в защищённые.
- Запуск сервиса обёрнут в fallback (startForegroundService → startService).
