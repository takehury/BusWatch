# Автобусы Красноярска — сборка для **HarmonyOS 2 / 3 / 4**

Готовая сборка: `dist/KrskBusWatch-harmony-1.70.apk` (1,5 МБ, подписана v2+v3).

Это та же программа, что и основная, но собранная с учётом HarmonyOS:
часы не обязательны (ставится и на телефоны), нет зависимости от Google Play Services,
targetSdk 33 — наиболее совместимый с HarmonyOS 3/4.

> ⚠️ **HarmonyOS NEXT (5.x) не запускает APK.** Если у вас устройство на HarmonyOS NEXT,
> эта сборка не подойдёт — нужен нативный HAP-порт (ArkTS/ArkUI). Инструкция и заготовка
> лежат в соседней папке `../harmonyos-next/`.

## Чем отличается от основной сборки

| Параметр | Основная | HarmonyOS |
|---|---|---|
| `targetSdkVersion` | 33 | 33 |
| `android.hardware.type.watch` | необязательный | **необязательный** (ставится и на телефон) |
| `FOREGROUND_SERVICE_DATA_SYNC` | — | **да** (HarmonyOS на Android 13/14) |
| `hardwareAccelerated` | по умолчанию | **true** (плавнее анимации на Huawei) |
| Google Play Services | не используются | не используются |

## Установка

### Часы Huawei (Watch 3 / 4 / GT, HarmonyOS 2–4)
1. Включите на часах режим разработчика и **отладку по ADB** (в приложении Huawei Health
   или в настройках часов — зависит от модели).
2. Подключите часы и установите:

```bash
adb install -r KrskBusWatch-harmony-1.70.apk
```

### Телефоны/планшеты Huawei (HarmonyOS 2–4)
1. Настройки → О телефоне → 7 раз по «Номер сборки».
2. Настройки → Система → Для разработчиков → **Отладка по USB**.
3. `adb install -r KrskBusWatch-harmony-1.70.apk`

Если стоит другая подпись:

```bash
adb uninstall ru.krsk.buswatch
adb install KrskBusWatch-harmony-1.70.apk
```

## Управление

- **Колёсико/безель** — прокрутка (ротационный энкодер).
- **Нажатие на колёсико** — выбрать / назад.
- **Свайп вправо** — назад.
- **Кнопка «‹ назад»** — левая половина верхнего сегмента.
- **Долгое нажатие / нижняя кнопка часов** — настройки и меню остановки.

## Фоновое ожидание автобуса

Foreground-сервис с уведомлением, опрос каждые 10 секунд, `PARTIAL_WAKE_LOCK` до 2 часов.
На HarmonyOS 4 может потребоваться разрешить **автозапуск** приложения
(Настройки → Батарея → Запуск приложений → Автобусы → вручную), иначе система
может остановить сервис при выключенном экране.

## Сборка из исходников

```bash
JAVA_HOME=/tmp/jdk17home ./build.sh
# → dist/KrskBusWatch-harmony-1.70.apk
```

Требования: JDK 17, Build-Tools 34, Platform android-33. Подпись — общий
`keystore/debug.keystore` из корня проекта.

## Возможные проблемы

| Симптом | Решение |
|---|---|
| `INSTALL_FAILED_UPDATE_INCOMPATIBLE` | `adb uninstall ru.krsk.buswatch`, затем установить заново |
| Уведомления не приходят | Настройки → Уведомления → Автобусы → разрешить; отключить оптимизацию батареи |
| Сервис останавливается в фоне | Разрешить автозапуск и «работу в фоне» в настройках Huawei |
| Нет GPS-фикса в помещении | включите «Позиция» в настройках приложения (ручной выбор остановки «Я здесь») |
