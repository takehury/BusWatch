# Автобусы Красноярска — сборка для **Wear OS 3 / 4 / 5**

Готовая сборка: `dist/KrskBusWatch-wear-1.70.apk` (1,5 МБ, подписана v2+v3).

Это та же программа, что и основная, но собранная под требования новых Wear OS.
Круглый интерфейс, fisheye-список, колёсико, ожидание автобуса — всё сохранено.

## Чем отличается от основной сборки

| Параметр | Основная | Wear OS |
|---|---|---|
| `targetSdkVersion` | 33 | **34** (требование Wear OS 5 / Android 14) |
| `android.hardware.type.watch` | необязательный | **обязательный** — APK ставится только на часы и корректно фильтруется в Play |
| `FOREGROUND_SERVICE_DATA_SYNC` | — | **да** (обязательно с Android 14 для фонового ожидания) |
| `com.google.android.wearable.standalone` | — | **true** — часы работают без телефона |
| Google Play Services | не используются | не используются |

## Установка

1. На часах включите **Для разработчиков** → **Отладка по ADB** (Wear OS: Настройки → Система → Сведения → 7 раз по «Номер сборки», затем Настройки → Для разработчиков → Отладка по ADB).
2. Подключите часы к компьютеру (Wi-Fi ADB или док-станция) и выполните:

```bash
adb install -r KrskBusWatch-wear-1.70.apk
```

3. На часах откройте приложение из списка, разрешите **геопозицию** и **уведомления**.

Если ранее стояла другая подпись (например, сборка из другого архива):

```bash
adb uninstall ru.krsk.buswatch
adb install KrskBusWatch-wear-1.70.apk
```

## Совместимость

| Wear OS | Версия Android | Статус |
|---|---|---|
| Wear OS 3.0–3.5 | Android 11 | ✅ поддерживается (`minSdk 26`) |
| Wear OS 4 | Android 13 | ✅ |
| Wear OS 5 | Android 14 | ✅ (targetSdk 34, dataSync-разрешение) |
| Wear OS 2 и ниже | Android 7–9 | ⚠️ не собирается под 34; используйте основную сборку |

## Управление

- **Колёсико/безель** — прокрутка списка (ротационный энкодер).
- **Нажатие на колёсико** — выбрать маршрут / назад.
- **Свайп вправо** — назад (свайп никогда не закрывает приложение).
- **Кнопка «‹ назад»** — левая половина верхнего сегмента.
- **Долгое нажатие** или **нижняя кнопка часов** — настройки / меню остановки.

## Фоновое ожидание автобуса

Работает как foreground-сервис с уведомлением. На Wear OS 4/5 нужно разрешить
уведомления при первом запуске. Держится `PARTIAL_WAKE_LOCK` (до 2 часов), опрос
каждые 10 секунд. По прибытии — двойная вибрация и уведомление.

## Сборка из исходников

Требования: JDK 17, Android Build-Tools 34, Platform android-33.

```bash
JAVA_HOME=/tmp/jdk17home ./build.sh
# → dist/KrskBusWatch-wear-1.70.apk
```

Скрипт использует общий `keystore/debug.keystore` из корня проекта, поэтому подпись
совпадает с основной сборкой (обновление ставится поверх без удаления).

## Возможные проблемы

| Симптом | Решение |
|---|---|
| `INSTALL_FAILED_UPDATE_INCOMPATIBLE` | удалить старую версию: `adb uninstall ru.krsk.buswatch` |
| `INSTALL_FAILED_MISSING_SHARED_LIBRARY` | APK предназначен только для часов (watch required) |
| Нет уведомлений | Настройки → Приложения → Автобусы → Уведомления → разрешить |
| Не крутится список колёсиком | проверьте, что жест попадает на список, а не на часы; кнопки громкости тоже прокручивают |

## Данные

Публичный фид Bustime Красноярск (`https://busti.me/ajax/bus/?bus_id=…`), каталог
остановок и маршрутов зашит в APK. Приложение не требует Google Play Services.
