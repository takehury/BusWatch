# Как помочь проекту

Спасибо за интерес! Проект — открытое Android-приложение для часов.

## Сообщить об ошибке

Создайте issue и укажите:
- модель часов и версию ОС (например, Galaxy Watch 6, Wear OS 4);
- разрешение экрана (если знаете);
- версию приложения (видна в `versions/`);
- шаги воспроизведения и ожидаемое поведение.

## Предложить код

1. Форкните репозиторий, создайте ветку `feature/...`.
2. Соберите проект: `./run_tests.sh && ./build_apk.sh` (нужны JDK 17,
   Build-Tools 34, Platform android-33).
3. Добавьте тесты на новую логику в `app/tests/`.
4. Убедитесь, что проходят `./run_tests.sh` и `./run_tests.sh --live`
   (живой тест требует интернет).
5. Откройте pull request с описанием изменений.

## Стиль

- Java 8, без внешних зависимостей в основном приложении.
- Вся логика, которую можно проверить без Android, живёт в чистых классах
  (`Geo`, `Board`, `Catalog`, `RoutePageParser`, `Cities`, `Displays`).
- UI рисуется через `UiFrame`, поэтому его можно отрендерить тестом без эмулятора.
