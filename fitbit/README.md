# Автобусы для Fitbit OS

Живые позиции автобусов, троллейбусов и трамваев на часах Fitbit: список
маршрутов, остановки с прогнозом ожидания, выбор города и метка «жду автобус»
с вибрацией при прибытии.

Порт основной версии **1.28** для платформы **Fitbit OS 5.x** (JavaScript + SVG).

## Поддерживаемые устройства

| Устройство | ОС | Приложение |
|---|---|---|
| Fitbit Ionic (2017) | Fitbit OS 4 | ✅ (проверьте размер экрана в Studio) |
| Fitbit Versa / Versa Lite / Versa 2 | Fitbit OS 3–4 | ✅ |
| Fitbit Versa 3 | Fitbit OS 5.2 | ✅ |
| Fitbit Sense | Fitbit OS 5.2 | ✅ |
| Fitbit Versa 4 | Fitbit OS 5.3 | ✅ |
| Fitbit Sense 2 | Fitbit OS 5.3 | ✅ |
| Fitbit Charge 5 / Charge 6 | Fitbit OS (трекеры) | ❌ сторонние приложения не поддерживаются |
| Google Pixel Watch 1–3, Galaxy Watch 4+ | Wear OS | ❌ используйте `../wear-os/` |
| Новые модели 2025–2026 на Fitbit OS | Fitbit OS 5.x | ✅ при совместимости SDK |

> Fitbit OS не даёт сторонним приложениям работать в фоне: уведомление о
> прибытии срабатывает, **пока приложение открыто** (вибрация + метка).
> Фоновое ожидание, как в APK-версии, на этой платформе невозможно — это
> ограничение ОС, а не приложения.

## Архитектура

```
app/index.js        UI: SVG-строки, свайпы, состояния (маршруты/остановки/города)
app/core.js         чистая логика: гео, доска прогнозов, детектор прибытия
companion/index.js  сеть: страницы маршрутов Bustime, живой фид
companion/data.js   каталог: 22 города и 6430 маршрутов (503 КБ)
companion/core.js   та же логика для companion
test-core.mjs       48 тестов на чистой логике и данных
fixtures/           реальные страницы маршрутов и фид для тестов
```

`core.mjs` — единственный источник правды; `app/core.js` и `companion/core.js`
копируются из него (`./build.sh`), тест проверяет, что копии не разъехались.

## Тесты

```bash
node test-core.mjs      # 48 проверок
./build.sh              # синхронизация + тесты + сборка (если установлен SDK)
```

Проверяется: расстояние по haversine, выбор ближайшего города, разбор страницы
маршрута (СПб и Новосибирск), разбор фида (22 машины), построение доски,
дедупликация, фильтрация по направлению и возрасту, детектор прибытия,
форматирование, целостность каталога и синхронность копий ядра.

## Сборка и установка

Fitbit-приложения собираются только через официальный SDK (в нём же подпись).

```bash
npm install          # @fitbit/sdk, @fitbit/sdk-cli
npm run build        # → build/fitbit.fba
```

Установка на часы:

1. В приложении Fitbit на телефоне включите **Developer Bridge**
   (Настройки → Разработчик).
2. `npx fitbit` → `connect device` → `install`.
3. Либо загрузите папку в **Fitbit Studio** и соберите там.

Сборка в этом репозитории не выполняется: SDK требует npm-доступ и учётную
запись разработчика, поэтому `build.sh` собирает пакет только при наличии
`node_modules/.bin/fitbit-build`, иначе печатает инструкцию.
