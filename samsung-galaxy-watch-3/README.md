# Автобусы Красноярска — порт для **Samsung Galaxy Watch 3**

> ## ⚠️ Главное про совместимость
>
> **Galaxy Watch 3 работает на Tizen 5.5, а не на Wear OS.** Android-APK из корневой
> папки и из `models/wear-os/` на этих часах **не установится** — это другая ОС.
>
> Для Galaxy Watch 3 нужен нативный пакет **`.wgt`** (Tizen Web App). Он и лежит здесь:
> `dist/KrskBusWatch-tizen-1.0.0.wgt` — исходный, **неподписанный** пакет.
>
> Если у вас на самом деле Galaxy Watch **4 / 5 / 6 / 7** (они на Wear OS) —
> используйте `../wear-os/`.

## Что внутри

| Файл | Назначение |
|---|---|
| `app/index.html`, `style.css`, `app.js` | интерфейс Tizen Web App (круглый экран 360×360) |
| `app/core.js` | чистая логика: геодезия, разбор фида Bustime, доска ЭТА |
| `app/config.xml` | манифест Tizen: профиль `wearable`, привилегии, доступ к сети |
| `app/data/*.json` | каталог 74 маршрутов и списки остановок (те же, что в APK) |
| `test-core.js` | 20 тестов логики (Node, без DOM) |
| `build.sh` | тесты + упаковка `.wgt` |

## Возможности

- Список маршрутов (автобусы, троллейбусы, трамваи, маршрутки).
- Полный список остановок выбранного направления с ЭТА и пометкой «здесь».
- Ваша остановка подсвечивается зелёной меткой «вы».
- Переключение направления (тап по верхней зоне экрана остановок).
- Ручная позиция «Я здесь» (долгое нажатие на остановке).
- Ожидание автобуса: вибрация + уведомление Tizen при прибытии на отмеченную остановку.
- Вращающийся безель: событие `rotarydetent` листает список.
- Свайп вправо — назад; аппаратная кнопка «назад» — тоже назад.

## Сборка и установка

### 1. Tizen Studio
Установите **Tizen Studio 4.6+** с расширением **Wearable** и **Samsung Certificate
Extension** (сайт developer.samsung.com).

### 2. Сертификат (обязательно)
`Tools → Certificate Manager → Samsung → Create` — создаётся профиль **author** и
**distributor** сертификатов. Нужен аккаунт Samsung (бесплатный). Без этого шага
часы не установят пакет.

### 3. Подпись и сборка
```bash
cd models/samsung-galaxy-watch-3
./build.sh                 # тесты + dist/*.wgt (неподписанный)
```
Затем в Tizen Studio: `File → Open Project → app`, выбрать профиль сертификата,
`Project → Build Signed Package`. Либо из CLI:
```bash
tizen package -t wgt -s <имя_профиля> -- dist/KrskBusWatch-tizen-1.0.0.wgt
```

### 4. Установка на часы
1. На часах: Настройки → О часах → Сведения → 5 раз по «Номер сборки» → режим
   разработчика; Настройки → Для разработчиков → **Отладка по Wi-Fi** (IP показывается
   на экране).
2. На компьютере:
```bash
sdb connect <IP_часов>:26101
sdb install KrskBusWatch-tizen-1.0.0-signed.wgt
```

## Управление

| Действие | Что делает |
|---|---|
| Вращение безеля | прокрутка списка |
| Касание строки | открыть маршрут / выбрать остановку |
| Долгое нажатие на остановке | меню «Я здесь» / «Ждать автобус» |
| Свайп вправо | назад |
| Аппаратная «назад» | назад |
| Тап по верхней зоне экрана остановок | сменить направление |

## Ограничения Tizen-версии

- **Фоновое ожидание** работает только пока приложение открыто: Tizen Web App не может
  держать фоновый сервис без отдельного нативного приложения-сервиса (Tizen Service App,
  C/`.wgt` с `service`-профилем). В текущей версии опрос идёт каждые 10 секунд, пока
  экран приложения активен; для фона нужен отдельный сервисный модуль.
- Сетевой доступ к `busti.me` разрешён через `<access origin="*"/>` в `config.xml`;
  если прошивка строгая — добавьте домен явно.
- Внешний вид упрощён относительно Android-версии: строки списка повторяют круглую
  форму, но без полноценного fisheye-масштабирования текста.

## Проверка

```bash
node test-core.js
# TIZEN CORE: 20 passed, 0 failed
```

Тесты покрывают геодезию, разбор реального ответа Bustime, построение доски,
фильтрацию спящих/устаревших машин, ЭТА и разбор направлений. Интерфейс проверен
синтаксически (`node --check`) и вручную по структуре; запуск на часах требует
подписи Samsung, поэтому в этой среде недоступен.

## Данные

Публичный фид Bustime Красноярск: `https://busti.me/ajax/bus/?bus_id=<id>`.
Каталог маршрутов и остановок — в `app/data/` (копия из Android-версии).
